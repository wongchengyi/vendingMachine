# Kawaii Vending Machine

Welcome to the Kawaii Vending Machine project! This is a virtual vending machine inspired by Japanese culture, designed with a soft, cute, and kawaii aesthetic. The project features a charming interface, interactive elements, and delightful animations.

## Features

- **Pastel Color Palette**: The design incorporates sakura pink, milk white, soft mint, baby blue, and warm butter yellow accents.
- **Rounded Aesthetic**: All elements have chunky border radii and pillowy shadows, creating a friendly and inviting look.
- **Japanese Typography**: The project uses rounded fonts like "Zen Maru Gothic" and includes small Japanese labels for an authentic touch.
- **Interactive Vending Machine**: Users can insert coins, select drinks, and receive change, all while enjoying cute animations and sounds.
- **Cute Drink Illustrations**: Each drink is represented by an adorable SVG illustration with a kawaii face and bilingual labels.
- **Responsive Design**: The vending machine is fully responsive and works seamlessly on mobile devices.

## Getting Started

To run the Kawaii Vending Machine project locally, follow these steps:

1. **Clone the Repository**:
   ```
   git clone <repository-url>
   cd kawaii-vending-machine
   ```

2. **Open the HTML File**:
   Open `index.html` in your web browser to view the vending machine.

3. **Interact with the Machine**:
   - Click on the coin buttons to insert coins.
   - Select a drink to see it drop with a bounce animation.
   - Enjoy the sounds and animations as you interact with the machine!

## Design Choices

- The background features a dreamy Tokyo side street at dusk, created using CSS/SVG for a whimsical atmosphere.
- The vending machine includes a glowing top sign, drink slots, and interactive buttons that enhance user experience.
- Special interactions, such as the "あたり!" lucky event, add an element of surprise and joy.
